# 45–60 Second Portfolio Demo Script

## 0–8 seconds — Desktop hero
Show the desktop home page.

Say:
> This is a responsive small-business website I built with HTML, CSS, and vanilla JavaScript.

## 8–22 seconds — Services and featured work
Scroll through the Services and Featured Project sections.

Say:
> The layout is designed around clear business messaging, service presentation, and strong calls to action, with responsive CSS Grid and Flexbox layouts.

## 22–36 seconds — Interactions
Open one or two FAQ items and scroll to the contact form.

Say:
> JavaScript handles the mobile navigation, FAQ accordion, contact-form validation, success feedback, and other lightweight interactions.

## 36–48 seconds — Mobile view
Switch to a narrow/mobile browser view.

Say:
> The site adapts for mobile and tablet widths, with navigation and content layouts changing for smaller screens.

## 48–60 seconds — Finish
Return to the desktop hero or GitHub repository.

Say:
> This project demonstrates the type of clean, maintainable website I can adapt for local businesses, consultants, agencies, and professional services.

## Recording tips
- Keep the recording under one minute.
- Use 1080p if possible.
- Hide personal notifications and bookmarks.
- No webcam is necessary.
- Simple screen recording is enough.
