# Upwork Portfolio Entry

## Title
Responsive Small Business Website — HTML, CSS & JavaScript

## Role
Front-End Developer

## Description
Designed and developed a responsive website for a fictional small-business technology company using HTML, CSS, and vanilla JavaScript.

The project includes a modern landing page, services section, featured case study, responsive navigation, FAQ accordion, and validated contact form. The layout adapts across desktop, tablet, and mobile screen sizes and uses semantic HTML and accessibility-minded interactions.

The website was built without a front-end framework to demonstrate strong core HTML, CSS, responsive design, and JavaScript fundamentals.

Technologies: HTML5, CSS3, JavaScript, CSS Grid, Flexbox, Responsive Web Design.

1. Web Development
2. HTML
3. CSS
4. JavaScript
5. Responsive Web Design
