# Northstar Digital — Responsive Small Business Website

A polished, responsive small-business website built as a front-end portfolio project using **HTML, CSS, and vanilla JavaScript**.

The fictional client, **Northstar Digital**, provides websites, automation, and IT support for small businesses. The project demonstrates the kind of practical front-end work commonly requested in freelance website projects.

![Desktop website preview](screenshots/desktop-home-preview.jpg)

## Features

- Responsive desktop, tablet, and mobile layouts
- Fixed navigation with mobile menu
- Modern hero section and service cards
- Featured project / case study section
- Multi-step process section
- Testimonial block
- Accessible FAQ accordion
- Contact form with client-side validation and success feedback
- Scroll reveal interactions
- Reduced-motion accessibility support
- Semantic HTML and accessibility-minded structure

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Responsive Web Design
- CSS Grid
- Flexbox

## Run locally

No build tools are required.

Open `index.html` directly in a browser, or run a lightweight local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## JavaScript interactions

The project includes JavaScript for:

- Mobile navigation
- FAQ accordion behavior
- Form validation
- Form success toast
- Dynamic footer year
- Scroll-based header state
